# 响汽音乐人格制造所

## 运行与提交结构

无需安装依赖或填写 API Key，直接打开 index.html。也可将本目录全部网页文件上传 HTTPS 静态托管，参与、作品、券码二维码将自动启用。二维码库已本地打包，无外部运行依赖。

提交根目录只包含：01_网页原型与源码、AIGC互动营销大屏-产品方案-郭梓萱.pdf、03_AI工具使用说明.md。PDF 为一页；AI 使用说明中的本人修改段保持原文。

## 演示路径

1. 点选人格、风格和预设宣言，生成海报；可保存 PNG 或调用系统分享。
2. 输入“测 试辱 骂”或“测试色情”，验证分类拦截，再点“改用安全模板重试”。正式版以服务端审核为准，演示词库不能覆盖谐音隐喻。
3. 勾选公开展示与品牌使用授权，再点授权上屏，并在弹窗二次确认。每个浏览器会话只能授权一次，修改内容、重新生成和超时复位不会恢复次数。
4. 舞台大屏逐张展示，每张 8 秒；队列最多 6 张。可“下架当前”或清空演示队列。下次公开审核选“不通过”可验证拒绝状态（建议使用新浏览器会话测试）。
5. 领券获得唯一演示券码。公网版扫描券二维码自动核销，本地版可点模拟核销；同浏览器重复核销会拦截。无真实兑换权益。
6. 体验说明页展示正式方案与原型对照、本会话事件流水；大屏显示本设备今日参与数。

## 生产方案与原型边界

本地海报不自动上公共大屏。手机作品二维码包含 Base64 编码参数，可还原同款；Base64 不等于加密，正式版采用短期、不可枚举的作品 ID。

纯静态版队列与授权撤回在当前浏览器演示，不跨设备同步。券码核销在核销浏览器 localStorage 防重复，不能保证跨设备一码一销，也不能校验服务端签名。正式版需统一队列、授权管理、服务端签发和原子核销，并对接神策或 GrowingIO 聚合全场数据。

顶部品牌条为图片固定组成部分，导出不会遗漏；第三方仍能裁切图片，6% 水印降低品牌完全丢失的概率，不能禁止裁切。

## 本轮修改验收

1. 只保留一个提交目录和同名 zip；产品方案改为唯一一页 PDF。
2. 清理旧副本及其中的候选人备忘，当前 AI 本人修改段保持原样。
3. 最小演示词库按五类组织，移除真实人物姓名，注释说明热更新方案。
4. 审核前去空格/零宽、NFKC 全半角转换与小写。
5. 增加安全模板自动重试、下架当前按钮。
6. 生成授权和公开/品牌使用授权分开，公开默认不选，30 天期限、撤回入口、二次确认。
7. 公网发布待平台确认与发布凭据；GitHub 浏览器未登录，GitHub Pages / Vercel CLI 无发布凭据。未伪造线上链接或线上验证结论。
8. 补容量论证：60 人/小时/台、450 张/小时/屏；640 人分散 4 小时需 3 台，集中 1 小时需 11 台；扫码为主机位兜底。
9. sessionStorage 限制每浏览器会话上屏 1 次，正式版设备风控标识/手机号幂等去重。
10. 审核中、未通过及品牌待机状态，拒绝不进入队列。
11. 顶部 130px 品牌条、底部署名、6% 符号水印。
12. 六类事件写入 localStorage 与控制台；会话流水、本设备今日参与数。
13. 时间戳+随机标识唯一演示券码，扫码核销与本地重复拦截；服务端一码一销写入正式方案。
14. 三个人格绑定三种构图，种子仅在各自结构内微扰。
15. 三条可点选、可编辑预设宣言。
16. Base64URL 参数与复原说明；正式版作品 ID 写入方案。
17. 两列正式版方案与原型实现对照。
18. 800px 以下人格按钮单列，手机为主要路径。
19. button 最小高度 44px，padding 13px 18px；标签页 tablist/tab/aria-selected，支持左右键及 Home/End。
